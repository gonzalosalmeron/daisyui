Countdown keeps the page busy

The digits of .countdown move with a top transition of one second, and the value changes every second, so a transition that touches layout is always running.

12:34

To compare, record the page with Safari Web Inspector (Timelines, Layout & Rendering) or the Chrome Performance panel for a few seconds in each mode, and look at how often style recalculation and layout run. If you open the file directly, you can also pick a mode from the address bar with ?mode=current, ?mode=proposed, ?mode=proposed-fast, ?mode=elements or ?mode=none.
